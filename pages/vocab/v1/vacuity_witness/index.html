vacuity_witness

Term URI: https://w3id.org/agent-evidence/vocab/v1/vacuity_witness

Section: evaluation_claim. Criticality: critical.

Whether a property reported as holding on all traces was ever exercised. An all-traces property holds trivially over a model with no honest trace, and a case set that counts such a result as a pass reports coverage it does not have. The witness is a separate, declared check that the guarded state is reachable; a pass whose witness is falsified is a vacuous pass, a code of its own, and the case is recorded as not run.

Registered values

  • https://w3id.org/agent-evidence/vocab/v1/vacuity_witness#vacuous_pass: The property was reported as holding, and the witness for its precondition is falsified: no honest execution reaches the guarded state, so the property holds because nothing happens. The pass is refused.
