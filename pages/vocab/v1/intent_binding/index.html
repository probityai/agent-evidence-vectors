intent_binding

Term URI: https://w3id.org/agent-evidence/vocab/v1/intent_binding

Section: evidence_dimensions. Criticality: critical.

Whether the identifier of the intent an action ran under (the authority that permitted it, naming who requested it and who executed it) is folded into a commitment the observer signed BEFORE the action began (committed_before_execution), or only attached to the record once the action was over (asserted_after_execution). A committed identifier survives fan-out, retries and hops between agents as signed content: every record descended from one intent carries the same value inside bytes fixed before each action opened, so linking them needs no header that every hop must forward. An asserted identifier is a label a producer can choose after seeing the outcome. Composes by weakest input: a chain of actions is committed_before_execution only if every link is.
