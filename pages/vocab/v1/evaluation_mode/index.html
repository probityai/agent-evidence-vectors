evaluation_mode

Term URI: https://w3id.org/agent-evidence/vocab/v1/evaluation_mode

Section: change_admission. Criticality: critical.

How an evaluation result attached to an admission was obtained. Only FRESH counts toward a gate; a RECORDED or CACHED result is labelled as such in the report and excluded from every count a gate uses. Values are recorded in the casing the wire carries, upper case.

Registered values

  • https://w3id.org/agent-evidence/vocab/v1/evaluation_mode#FRESH: Produced by a run made for this decision, every model call answered fresh.
  • https://w3id.org/agent-evidence/vocab/v1/evaluation_mode#RECORDED: A stored FRESH result shown again, with the time it was produced.
  • https://w3id.org/agent-evidence/vocab/v1/evaluation_mode#CACHED: A byte-identical replay of a recorded model request, for debugging.
