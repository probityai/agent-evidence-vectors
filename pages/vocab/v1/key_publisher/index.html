key_publisher

Term URI: https://w3id.org/agent-evidence/vocab/v1/key_publisher

Section: principal_identity. Criticality: critical.

Which party publishes the key set a verifier trusts for a signed payment instruction or credential: the agent's own origin, or an issuer or network the verifier selected independently. It is read beside issuer_key_pinning, and the two together answer which origin vouches for the key and whether the verifier pinned it somewhere else first. A key set the agent's origin serves proves only that the origin holds the key, so a verifier that requires an independent publisher refuses agent_origin. Closed and fail-closed.
