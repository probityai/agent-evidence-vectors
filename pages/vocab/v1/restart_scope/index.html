restart_scope

Term URI: https://w3id.org/agent-evidence/vocab/v1/restart_scope

Section: multi_agent_run. Criticality: critical.

What a restart of one agent removed. The verifier computes the value from the restart entry: memory_and_cause_removed when the configuration digest before differs from the digest after, memory_only when they are equal. A restart that did not clear memory has no value: the journal is refused. Closed and fail-closed.

Registered values

  • https://w3id.org/agent-evidence/vocab/v1/restart_scope#memory_only: The agent's memory was cleared and its configuration digest is unchanged, so the cause it carried remains.
  • https://w3id.org/agent-evidence/vocab/v1/restart_scope#memory_and_cause_removed: The agent's memory was cleared and its configuration digest changed, recording the removal of the cause.
