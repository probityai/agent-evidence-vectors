set_sufficiency

Term URI: https://w3id.org/agent-evidence/vocab/v1/set_sufficiency

Section: posture_and_coverage. Criticality: critical.

Whether the evidence SET a claim rests on was relevant and sufficient to reach the claim, held as a separate axis from whether any individual ITEM in it was reliable. A set of items each independently verified can still be too thin to decide, and a single unreliable item can sit inside a set that is otherwise ample. Collapsing the two axes into one pass or fail makes both unsayable. The value is REQUIRED and fail-closed. Absent, non-string or unregistered makes the enclosing statement malformed, and absence is never read as sufficient. A verifier MUST NOT derive this value from item-level verification results, and MUST NOT read sufficient as a statement about any item. insufficient is a result and not an error: it says the assessment ran and the set did not reach the claim. not_assessed says the axis was never examined, and a consumer MUST treat those two as different.
