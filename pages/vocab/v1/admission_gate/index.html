admission_gate

Term URI: https://w3id.org/agent-evidence/vocab/v1/admission_gate

Section: change_admission. Criticality: critical.

The closed names of the checks an admission rests on, carried as checks[].name with a boolean checks[].passed. The consumer pins which gates it requires. A required gate absent from the record leaves the decision not established. A check whose name the consumer does not require, such as a cost report, is informational and never a gate. Closed and fail-closed: a consumer requiring a name outside this set has no definition to check it against.
