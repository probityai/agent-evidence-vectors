revision_reason

Term URI: https://w3id.org/agent-evidence/vocab/v1/revision_reason

Section: record_lifecycle. Criticality: informational.

A closed code stating why one entry in a record's revision history exists, carried beside a free-text reason so a consumer can count and filter revisions by cause without parsing prose. One code per revision entry. The entry it belongs to is an element of an optional, append-only revisions array on the record, each element carrying date, field, from, to, reason and reason_code. A record with no revisions array makes no claim about its own history; a consumer MUST NOT read its absence as "never revised". Closed and fail-closed: an unregistered reason_code makes the entry malformed.
