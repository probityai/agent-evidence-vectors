conformance_extension

Term URI: https://w3id.org/agent-evidence/vocab/v1/conformance_extension

Section: evaluation_claim. Criticality: informational.

An identifier an agent card or capability document lists among its declared extensions to state that the records its agent emits are judged by a named corpus revision under a named verifier. The identifier is this term's own URI, https://w3id.org/agent-evidence/vocab/v1/conformance_extension, written inside the signed card, so the statement is covered by the card's signature: removing it invalidates the card. Its params object carries exactly four members, each a non-empty string: corpus (the corpus package name), corpus_version, verifier (the verifier package name) and verifier_version. A version is one exact release in one spelling: a normalized PEP 440 public version (0.7.0, 1.0rc1, 0.7.0.post1, 2.0.dev3) or a SemVer 2.0.0 version without build metadata (1.0.0-rc.1). Leading zeros, spellings PEP 440 normalizes away (1.0-rc1, 1.0.0alpha), an epoch, a local label, build metadata and any range, operator or wildcard are refused. The card lists the extension once. The statement is a claim by the card's signer that a third party checks by running the named verifier on the named corpus; it is never a claim that the agent behaves well.
