evidence_state

Term URI: https://w3id.org/agent-evidence/vocab/v1/evidence_state

Section: incident_response. Criticality: critical.

The state of the evidence about one system at one time, as nine codes ordered from silence to a requested restart. Each code is defined only by what a responder can observe: whether an anomaly is recorded, whether the coverage of the monitors was measured, whether a change-detection threshold was crossed, whether propagation and its pathway were observed, whether the scope is bounded and containment verified, whether effects outside the organisation are confirmed, and whether containment is recorded and a restart requested. A record's state is the highest code whose entry condition its observations meet. The code says what was observed; it does not say what response is right, and it does not decide whether a restart is admitted. Closed and fail-closed: an absent or unregistered value where a record requires one makes the statement malformed.
