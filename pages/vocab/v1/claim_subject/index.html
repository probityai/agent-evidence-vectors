claim_subject

Term URI: https://w3id.org/agent-evidence/vocab/v1/claim_subject

Section: posture_and_coverage. Criticality: critical.

The class of subject a claim is about. A claim at one class is never evidence at another: a result about a tool's definition says nothing about an agent that called it, and a result about an agent's run says nothing about the organization that operates it. A consumer MUST NOT satisfy a requirement stated at one class with a claim carrying another, and a claim with no declared class MUST be treated as not satisfying any class-specific requirement.

Registered values

  • https://w3id.org/agent-evidence/vocab/v1/claim_subject#tool: A callable capability with a fixed definition, such as an MCP tool, a function exposed to a model, or a server's tool manifest. A claim at this class is about that definition and the code behind it.
  • https://w3id.org/agent-evidence/vocab/v1/claim_subject#agent: A running system that chooses which tools to call and with what arguments. A claim at this class is about the decisions and effects of that system during a stated run.
  • https://w3id.org/agent-evidence/vocab/v1/claim_subject#organization: The party that operates, deploys or answers for agents and tools. A claim at this class is about its controls, keys or accountability.
