# Sigstore-source DSSE threshold consumer

Verify offline Ed25519 envelopes with actual pinned Sigstore JS signature and
PAE functions. The owned consumer counts distinct trusted key identities and
hands back the exact verified bytes.

From the repository root, with Node 24:

```bash
node interop/sigstore-js-threshold-2026-10-04/replay.mjs sigstore-consumer.json
node --test interop/sigstore-js-threshold-2026-10-04/consumer.test.mjs
cargo test --all-features --test sigstore_js_profile
```

The replay checks all 11 unchanged Go-produced fixtures and 17 authored finite
controls. The Rust test checks the same controls using this crate's native API.
The original reference fixtures are never regenerated by this consumer.

Install the standalone consumer into a new directory:

```bash
node interop/sigstore-js-threshold-2026-10-04/install.mjs ./sigstore-consumer
node sigstore-consumer/cli.mjs envelope.json policy.json report.json
```

The policy file has a positive integer `threshold` and a `keys` array. Each
entry has `id` and `key`, a trusted Ed25519 public key in PEM form. A threshold
above one requires both distinct labels and distinct actual keys. The CLI
clears an old passing report before checking new inputs and refuses duplicate
JSON members. It returns the verified payload in the report as base64.

The [source manifest](source-manifest.json) records immutable originals,
attribution, exact hashes and runtime import adaptations. Vendor files stay
unchanged. This executes retained source functions rather than an installed
`@sigstore/verify` package. The native class still selects its first signature;
the consumer invokes it separately for each candidate entry.

This profile checks DSSE signature integrity under supplied keys. Key authority,
native task state, committed target effects, consumer publication, certificate
chains and transparency logs retain their own decisions. Controls are
author-operated PEER work, outside adoption is pending, and the separate
eight-task prospective implementation-owned study has not started.

See [the consumer contract](../../docs/SIGSTORE-JS-THRESHOLD.md).
