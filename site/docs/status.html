Verification, host use and paid use

A verification or reproduction checks selected inputs with a named reader. Host use needs separate evidence that the host keeps and runs the integration. The Packslip observation retains one historical successful host test step and a published development dependency. Its regression was author-contributed; the Atlas metadata reading is Probity-operated. Neither a retained test nor a development dependency establishes a production deployment, an independently observed effect or paid use. Those claims need their own evidence. Registry download counts measure requests. They do not count users, maintained integrations or revenue.

Open cells: take one

An open cell is a mechanism and a property where the mechanism’s own documentation, or the text that defines it, says it cannot establish the property. Start with these:

  1. Declarative policy decision point (OPA, Cedar, OpenFGA, Kyverno) x Effect (did the downstream system commit the effect?). Limit: “a decision precedes execution and cannot observe the result” source (states the scope). Take it: a passing case binds an allow decision to an effect observed from a vantage the decider does not control.
  2. Signature over a canonical JSON or CWT record (RFC 8785 JCS, JWS) x Occurrence (did the recorded event actually happen, rather than being asserted?). Limit: “TRACE LIMITATIONS: a privileged operator can produce a valid-looking Level 0 record for a run that never happened” source (states the limit). Take it: a passing case refuses a well-signed record with no independent observation of the run.

To take a cell, open an Evidence run issue naming it. Listing a cell makes no claim about who closes it; a run that does is recorded in the Lab like any other.

How this page is derived

Verdicts: pass is ESTABLISHED, fail is CONTRADICTED, and not-exercised and out-of-scope are NOT_ESTABLISHED, with out-of-scope results labelled. A verdict holds only at the record’s evidence class. unknown stays distinct: the observation cannot settle the claim. It is neither a failed claim nor a check that was not exercised, and it is counted separately.

Operation class, first match wins, from the record’s own roles: independently operated only when independentOperation or independentOperator is exactly established; Probity-operated when an operator role (runner, atlasOperator, fixtureOperator, historicalRunner, diagnosticRunner or atlasReplay) names Probity; otherwise author-operated, where an operator role names the author of the fixture or software under test.

The page is regenerated by python3 tools/gen_status.py, and python3 tools/build.py --check fails when it is stale. Open cells come from data/open-cells.toml, written by tools/export_open_cells.py, which keeps a cell only when an excerpt of its source page was found there.
